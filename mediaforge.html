This page opens MediaForge in a separate tab. It does not ask for or store your API key, proxy media, or change Vivid's VidAPI player.

What this connection means

01

Local first

On the PC running MediaForge, localhost:8080 points to that PC. Other devices need a separately configured reachable server.

02

Keep downloads there

Downloads and library files remain managed by your MediaForge installation and its configured storage.

03

Player stays untouched

Vivid's current Watch Now and Play Episode flow continues using its existing player integration.
