Install with Safari

Apple's iPhone installation uses Safari's built-in Add to Home Screen option. Follow these four steps.

  1. 01

    Open this page in Safari

    Use Safari on your iPhone or iPad and visit the official Vivid Cinema website.

    ◎
  2. 02

    Tap the Share button

    In Safari, tap the square with the upward arrow. It is usually in the bottom toolbar.

    ↑
  3. 03

    Choose “Add to Home Screen”

    Scroll through the Share menu if you do not see the option straight away.

    ＋
  4. 04

    Confirm by tapping “Add”

    If Safari shows “Open as Web App”, leave it enabled. Vivid Cinema will appear on your Home Screen.

    ✓
Open Vivid Cinema ↗

If you are viewing this page in another browser, open the Vivid Cinema website in Safari to use these steps.

Is this a native IPA?

No. This is the official installable web app (PWA). It is the supported public iPhone installation route and does not require a developer trust certificate.

Will it work like an app?

It opens from its own Home Screen icon in a standalone window. Some capabilities, especially background playback and offline media, remain subject to iOS and website support.

Do I need to pay to install it?

No. Installing Vivid Cinema this way has no extra subscription or installation fee. Existing third-party services and their usage limits still apply.
